# Нехватка памяти и OOM killer

Алерт «Заканчивается память» или в журнале ядра `Out of memory: Killed process`.

## Как подтвердить

```bash
free -h
sudo dmesg -T | grep -i -E "out of memory|killed process" | tail
ps aux --sort=-%mem | head -15
```

## Что делать

1. Найти процесс-потребитель (`ps aux --sort=-%mem`). Если это приложение с утечкой
   (память растёт «пилой» и сбрасывается только при рестарте) — перезапустить сервис и завести задачу
   на поиск утечки.
2. Для Gunicorn ограничить жизнь воркера: `--max-requests 1000 --max-requests-jitter 100`.
3. Для Celery: `--max-tasks-per-child 100` и `--concurrency` не больше числа ядер.
4. Ограничить память сервиса через systemd: `MemoryMax=1G` в юните, чтобы OOM убивал его, а не базу данных.
5. Если памяти просто мало — добавить swap как временную меру или увеличить RAM.

## Чего не делать

Не отключайте OOM killer (`vm.overcommit_memory=2` без расчёта) и не перезагружайте сервер
без выяснения причины: проблема вернётся.
